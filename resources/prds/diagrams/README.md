# Mermaid Diagram Workflow

This directory stores Mermaid diagrams generated from architectural documentation that supports PRDs in `resources/prds/`.

## Purpose

Use these diagrams to capture:

- system components
- data flows
- service interactions
- boundaries and responsibilities
- request or event sequences when they matter to implementation

## Naming

Use descriptive names tied to the PRD, for example:

- `merchant-onboarding-system-context.mmd`
- `merchant-onboarding-sequence-checkout.mmd`
- `storefront-tenancy-data-flow.mmd`

## Usage

PRDs should reference the relevant Mermaid diagram files in their `Architecture / Diagram References` section.

If architecture is unclear, do not guess. Ask clarifying questions before generating the diagram.
